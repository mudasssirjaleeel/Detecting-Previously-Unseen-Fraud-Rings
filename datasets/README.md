# CORAL datasets

## Synthetic benchmark (included here)
Generated by `coral.data.generate_synthetic` (see the notebook, section 8). Columns:
`ts` (seconds from start), `src`, `dst` (account ids), `amount`, `is_laundering` (0/1),
`pattern_id` (laundering pattern instance, -1 = normal), `typology` (FAN-IN, FAN-OUT, CYCLE,
BIPARTITE, STACK, SCATTER-GATHER, GATHER-SCATTER; empty = normal).

| File | Role in the paper |
|---|---|
| coral_synthetic_heldout_seed7.csv.gz | Held-out world: all reported results |
| coral_synthetic_dev_seed11.csv.gz | Development world: all design decisions |
| coral_synthetic_heldout_seed7_drift.csv.gz | Drift stress test (bill-splitting product in the test period) |

## Public datasets (download from the source)
- IBM Transactions for Anti Money Laundering (AMLworld), Kaggle:
  https://www.kaggle.com/datasets/ealtman2019/ibm-transactions-for-anti-money-laundering-aml
  Files used: HI-Small_Trans.csv, HI-Small_Patterns.txt (also LI-Small, Medium, Large).
  Paper: Altman et al., "Realistic Synthetic Financial Transactions for Anti-Money Laundering Models",
  NeurIPS 2023 Datasets and Benchmarks, https://arxiv.org/abs/2306.16424
- IBM AMLSim simulator: https://github.com/IBM/AMLSim

## IBM AMLSim worlds (included here)
Generated with IBM AMLSim (https://github.com/IBM/AMLSim, commit 7338a4b), 10K-account parameters, 8 typologies × 30 alerts, 200 days, with the disclosed patches in `coral/amlsim_tools/` (including the bipartite/stack label fix).
- `amlsim_heldout_seed0/`: held-out world (reported results)
- `amlsim_dev_seed1/`: development world (configuration choice)
Each folder has `tx_log.csv.gz` (simulator output) and `alert_members.csv.gz` (alert typologies). Load with `coral.data.load_amlsim(tx_log, alert_members)`.
